#Artificial Intelligence Lab 1 - Steering
##Project organization
The project is separated into three scenes:
- Behvior Graph
    Seek and Flee behaviors implemented using Graphs. When the agent is seeking and reaches the player, starts fleeing until it reaches a safety distance, and then starts seeking again.
- Code implementation
    Seek and Flee behaviors implemented using code. When the agent is seeking and reaches the player, starts fleeing until it reaches a safety distance, and then starts seeking again.
- Flocking System
    The flock of a variable ammount of penguins is contained within an invisible sphere of 15 units of radius. Inside this sphere, there are 3 obstacles (which have to be moved to an "Obstacles" layer, and that layer selected in the Obstacle Filter scriptable object) that the penguins will avoid.
    The flock contains also a variable ammount of leaders (colored in red) that will be followed by the other penguins.
